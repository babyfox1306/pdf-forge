# Change Log

All notable changes to the "PDF Forge" extension will be documented in this file.

## [1.0.0] - 2025-01-XX

### Added
- Initial release of PDF Forge
- PDF viewer with pdf.js integration
- Text extraction with selectable text layer
- Code block detection and extraction
- Syntax highlighting for 50+ languages
- Automatic code deduplication
- Table extraction to CSV/JSON
- PDF to Markdown conversion
- Markdown to PDF conversion
- Full-text search with regex support
- Highlight, notes, and bookmarks
- PDF comparison (diff mode)
- OCR integration with Tesseract.js
- Metadata inspector
- Smart copy with citations
- Export system with organized folder structure
- Git integration for auto-committing exports
- 15 commands and 6 keyboard shortcuts
- Dark mode support
- Auto-reload on file changes
- Large file support (>200MB)
- Cross-platform support (Windows/macOS/Linux)
- 100% offline operation

### Technical Details
- Publisher: babyfox1306
- Extension ID: pdf-forge
- Activation: onCustomEditor:pdf-forge.pdfEditor
- Dependencies bundled: pdf.js, Tesseract.js, highlight.js, diff-match-patch, md-to-pdf
